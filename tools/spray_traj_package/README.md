# spray_traj — 点云喷粉轨迹生成工具

从物体表面轮廓扫描生成的点云（PLY）中，自动生成可引导机器人进行**喷粉作业**的轨迹，
包含机器人末端**位置 + 姿态（四元数）**、行进速度、分区信息等完整数据。

纯 C++ 实现（C++17，无第三方依赖），单文件编译即可使用。

---

## 3. 使用方法

```bash
./bin/spray_traj.exe --input <工件点云.ply> --outdir <输出目录> [选项]
```

### 命令行参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--input` | （必填） | 输入 PLY 点云 |
| `--outdir` | `out` | 输出目录 |
| `--pass-spacing` | `100` | 之字轨迹行距（mm）。喷粉出粉量大，建议 ≥100 |
| `--standoff` | `200` | 喷枪工作距离（mm），枪位置沿表面法向偏置 |
| `--max-hole-area` | `5000` | 封闭小孔面积上限（mm²），≤ 此值的小孔被填充忽略、当平板喷 |
| `--grid-size` | `5` | 占据栅格分辨率（mm） |
| `--margin` | `15` | 边界腐蚀宽度（mm），防止枪贴到板边卷边 |

### 输入点云要求

- PLY 格式（ascii 或 binary_little_endian），含 `x y z` 顶点即可，法向不需要；
- 表面扫描点云，允许含有少量杂散噪点（自动去除）；
- 工件可以带小孔（自动忽略）和大孔（自动避开并绕行）。

---

## 4. 算法流程与工艺规则

处理流程：

1. **稳健平面拟合**：RANSAC ±6mm 找主平面（不受卷边/斜面干扰）；
2. **栅格化 + 去杂散**：占据栅格 → 最大连通域；
3. **边界腐蚀**：距离变换腐蚀 `margin`，保证枪离板边有余量；
4. **封闭孔检测**：背景域 BFS，面积 ≤ `max-hole-area` 的小孔直接填充当平板处理；
5. **大孔检测**：面积超限的封闭域判定为大孔，**轨迹必须避开**；
6. **斜面检测**：粗尺度高度场上用 known-cell 梯度法找陡坡区（如灶壳顶部斜面）；
7. **分区生成轨迹段**（见下）；
8. **串接**：段间过渡用 A* 最短路绕孔，**全程开枪不关闭**；
9. **姿态后处理**：法向插值 → 窗口平滑 → 限幅（每点 Z ≤ 8°、X ≤ 15°）→ 四元数输出。

### 分区工艺规则（核心）

| 区域 | 轨迹形态 | 姿态 |
|---|---|---|
| 主平面 | 横向之字，行距 `pass-spacing` | 垂直于主平面（toolZ = −n） |
| 小孔 | 无专门处理（填充忽略，当平板喷） | 同主平面 |
| 大孔 | **避开**，孔周走一整圈（半径 = 等效半径 + 偏置，逐毫米收缩直到放得下，放不下则贴边模式回退） | 垂直于主平面 |
| 顶部斜面 | **换姿态**，沿斜面长度方向走直线段 | 垂直于斜面自身法向 |
| 小卷边 | 忽略（由斜面喷涂覆盖） | — |

### 工艺铁律

- **靠近工件前先开枪，离开工件后才能关枪；枪与工件保持工作距离时绝不关枪。**
  因此段间过渡（换区、绕大孔、跨斜面边界）全部作为 spray 连续喷涂段输出，不存在 travel-off 段。
- 行距 ≥ 100mm（约为喷漆的 2 倍以上），区别于喷漆的密集轨迹。

## 5. trajectory.csv 字段说明

```
seq,zone,type,x_mm,y_mm,z_mm,qw,qx,qy,qz,toolz_x,toolz_y,toolz_z,speed_mm_s,pass,group,u_mm,v_mm,h_mm,su_mm,sv_mm
```

| 字段 | 说明 |
|---|---|
| `seq` | 点序号，机器人按此顺序执行 |
| `zone` | 分区：`plane`=主平面之字，`ring`=孔周整圆，`slope`=斜面区，`travel`=过渡段（spray 连续） |
| `type` | `spray`（全程均为喷涂，本工具不输出关枪段） |
| `x/y/z_mm` | 枪位置（世界坐标，已沿法向偏置 standoff） |
| `qw/qx/qy/qz` | 姿态四元数（toolZ 轴指向由四元数第三列给出，与 `toolz_*` 一致） |
| `toolz_x/y/z` | 喷枪轴向单位向量（冗余给出，便于校验） |
| `speed_mm_s` | 该点进给速度；拐角区自动降速 30% |
| `pass` | 第几条之字行（pass 内按序连接） |
| `group` | 段编号（同一 group 内连续执行） |
| `u/v/h` | 段局部坐标（h 为离面高度） |
| `su/sv` | 主平面投影坐标（过渡段寻路与串接用） |

四元数约定：喷枪 toolZ 轴指向工件表面（toolZ ≈ −法向），四元数已保证连续性
（q 与 −q 等价问题已处理），可直接喂给机器人控制器后按需转换为目标机器人姿态格式。

## 6. 已验证工件（回归测试）

| 工件 | 特征 | 结果 |
|---|---|---|
| p004 | 无孔平板 231×222 | 横向之字，行距 100 |
| p026 | 带小孔平板 292×175 | 小孔全部填充忽略，当平板喷 |
| p025 | 灶壳正面 654×376：两 Φ190 大孔 + 49.5° 顶斜面 + 小卷边 | 大孔绕行+孔周整圆、斜面换姿态沿长度走直线、卷边忽略 |
| p029 | 灶壳背面（斜面反向 −49.6mm 凹陷） | 斜面法向自动镜像适配，无需特殊处理 |

姿态质量校验：相邻点姿态步进 ≤ 15°、位置无跳变（最大 7.7mm，属过渡段贴卷边高度跟随的预期行为）、
toolZ 与各区法向一致。

## 7. 已知限制与后续方向

- 段串接顺序为就近贪心，未做全局顺序优化（TSP）；段很多的工件过渡段占比可能偏高（如 p029 约 41%）。
- 斜面区检测基于高度场梯度阈值，极端曲面（非平面+斜面组合）尚未覆盖。
- 大孔绕行半径自适应收缩在孔距板边过近时退化为贴边模式，圆度略有牺牲。
