
## 主程序 spray_traj.cpp：面内"端点选择"（空移最短）— 2026-11-17

需求：几段轨迹的空移绕远，应"找最近的端点作为起点，空移选最近的一段作为下一段"。目标文件是
`cpp/SprayTrajCore/spray_traj.cpp`（主程序），**不是** `tools/spray_traj_package`（那是交付包，误改过）。

### 已实现（保留）
- 平面面：`traj2` 生成完、面间过渡之前，比较首/末两端到上一面终点的距离，反走整段（`std::reverse`）。
  反走 = 行序+行向同时取反，走的是同一批线段，净空/穿面结论不变，不需重算。
- 曲面块：行序 + 每行点序同时取反（`revSurf`），行间 `emitGap` 起止端点随之取反；入口点 `kEntry` 跟着换。
- **出口闸**：反走会把出口换到另一端，必须验"出口那端退得出去"（法向退 + 抬到安全面的最小净空
  ≥ 0.9×gunClearEff），否则保持原方向。box_traj 的内半环 1→0 出得去、反向出不去，只按"入口近"
  反走会害得下一个面被判"无可行退出路径"整面丢掉（丢 2305 点）。

### 实测（air = 空移总长；无丢面变化）
- nc_complex：4998 → 4327 mm（-13.4%），点数 4743→4576，run 数不变，maxstep 仍 4.0mm
- box_traj / cao：不变；box_inner：9994 → 9941（-0.5%）

### 试过但**撤掉**：面顺序全局重排
用面心 / 面内包围盒四角 / 点集主方向四角三种代理 + 最近邻 + 2-opt 求"最近的下一个面"：
- nc_complex 上省 9%~13%，还能避免丢面；但 box_traj 空移 5171→6921（+34%）、box_inner 也退化。
- 根因：面间过渡的固定开销（退枪→抬到安全面→平移→落枪）比两端点直线距离更大，且取决于
  "枪是否在腔里、抬升要绕多远"，光看点集几何估不出来。结论写在代码注释里，避免以后再犯。
- 要可靠重排必须**两遍结构**：先按面生成轨迹拿到真实首末枪位，再排序 → 过渡也按实测代价挑。

## 面顺序重排：做成"最后处理"（不碰面内生成）— 2026-11-17 下午

用户明确纠正：**顺序优化是最后处理**，不要动平面/曲面各自的生成逻辑（我先前试过"两遍结构 + FaceBlock"，
已全部回退）。最终落点：`spray_traj.cpp` 里 allPts 组装完、转角平滑之前，新增
"5.面顺序重排 + 面间空移重建"。

### 做法
1. 生成侧只加一件事：每个面吐完自己的点后记 `faceSpan.push_back({beg,end,si})`（面内轨迹在 allPts 里的区间）。
   生成逻辑、就地过渡、端点选择全部保持原样（`SPRAYTRAJ_NO_REORDER=1` 可退化成旧的逐字节行为，用于 A/B）。
2. 后处理：按 faceSpan 取每面真实首末枪位/法向 → 用 `buildTrans()` 生成**真实过渡折线**量长度做边权 →
   `(mask, 面, 朝向)` 精确 DP（N≤13，开放式路径、起终点自由、每面可反走）→ 按新顺序重建
   `[过渡] + [面内轨迹]`，旧过渡点整段丢弃。
   不可行过渡（退枪/落枪撑不到 0.9×gunClearEff）边权记 1e5，于是"腔里的面出不来"自动排到末尾，
   不再需要手写"腔面收尾"。
3. `buildTrans` 是从原生成代码里抽出来的同一套逻辑（退枪腿用上一面姿态、进入腿用本面姿态），
   预估代价时传 nFixOut=nullptr 不计数。

### 实测（空移总长 / 面间空移）
- nc_complex 4327→**2999**（-30.7%），面间 2583→1255
- box_traj   5171→**3901**（-24.6%），面间 3430→2160（几何代理那版反而 +34%，这版是降的）
- box_inner  9941→**7873**（-20.8%），面间 6776→4708
- cao        1205→ **996**（-17.3%），面间 813→605
- 不变量：喷涂点集合逐点相同（只是顺序变）；run 数不变（无丢面）；maxjump 仍 4.0mm；
  相邻姿态差 ≤5°；空移点离工件最小距离与旧版一致（box_inner 1.6 / complex 9.6 / box_traj 8.1mm）。
- 耗时：box_inner 0.26s→0.55s（7 面 = 196 次 buildTrans），可接受。

### 坑

## 残白.ply 单平面出"斜单行"轨迹 —— 定位为行距≥面宽导致的布行退化（非离群点）
板面：242(长,≈-Z) × 40(宽) × 3.6(厚) mm，法向 (0.919,-0.394,0.014)，面积 8324mm²，RMS 3.587mm，内点 100%。
**先排除的假设**：点云在面内的投影 6937 点全部落在 242×40 轮廓内（带外 0 点），面内无离群点；
离面 >5mm 的 848 点只集中在两端（±18mm 极值），属卷边/倒角，没有撑歪最小外接矩形。→ 不是离群点问题。
**真因**：GUI 这次实际传给算法的 `scanRowSpacing = 60mm > 面宽 40mm`。用 `spray_driver -row 60` 复现，
点位与 GUI 导出的 24 点**逐点偏差 0.00mm**（点数 24、段长 3.951mm 也一致）。
**机制**（cpp/SprayTrajCore/spray_traj.cpp 布行段）：
1. 候选角度循环里 `if(rs.size()<2) continue;`（~6382）——行距>面宽时"正确方向（沿长边，只出 1 行）"被直接淘汰；
2. `cost = jag + rs.size()*L*0.02`（~6387）——L 越大越偏向"行数最少"，于是挑到斜角；
3. `按重建轮廓夹端点`（~6476/6509）再把 3 行丢 2 行 → 只剩 1 条斜线，并两侧各出界 ~22mm（b 到 ±42，板只到 ±20）。
**行距扫描实测**（驱动，同一份点云）：12→19行/0°；20→11行/0°；24→10行/0°；30→8行/0°；
40→4行/5°；60→1行/20°(24点)；100→1行/30°(40点)；150→2行/135°(133点)。
→ 行距 ≥ 面宽后行数/行方向开始退化；133 点那两次（早上/17:28）对应 row=150，24 点这次对应 row=60。
**可用规避**：行距 ≤ 面宽一半（本例 ≤20mm）。
**建议修复**：`rs.size()<2` 改为允许 1 行且把该行居中夹到面内；或 L>面宽时先 clamp L=面宽、只出居中 1 行。

## 同一问题的修复落地：残白"斜单行/出界"= 竖直面水平锁定 + 行距≥面宽退化（通用判据修复）
**同前一条记录**：点云面内投影 6937 点全在 242×40 轮廓内，无离群点问题；确认是布行方向/外扩判据。
**根因（三者叠加，均与零件尺寸无关）**
1. `fabs(pl.n.z)<0.3`（竖直面）把行方向锁到"面内水平"= 20°，而该板矩形长边在面内 88.5°
   → 行与长边差 68.5°，等于沿 40mm 短边布行；斜交重建轮廓后被 clipRowByLoops 整条判为面外。
2. 角度穷举兜底 `if(rs.size()<2) continue`：行距>面宽时"沿长边只出 1 行"的正确方向被直接淘汰。
3. 行端点盲扩 `extRow=0.25×scanRowSpacing` 与面尺度无关：row=150 时两端各伸 37mm（行 242→304）。
**已改（cpp/SprayTrajCore/spray_traj.cpp）**
- `slenderFace`：矩形长/宽 ≥ 3 的竖直面不锁水平，行方向=矩形长边（近方形侧壁行为不变）。
- 穷举允许单行候选：合法条件"跨行跨度 ≤ 1.2L"（跨度够两行却只出 1 行=被过滤的退化，跳过），
  单行按"行长"择优（cost -= rowLen*0.02）。
- `extRow = min(0.25L, max(3, 0.04×面内行向跨度))`，大行距不再把行推到面外几十毫米。
- 首末行豁免"轮廓缩水"裁剪（首末行按设计压边沿、行带只有一半有料，夹它就是制造空洞）。
- 新增调试开关 `SPRAYTRAJ_ROWCLIP_DBG`（打印每行 yc/xs/xe/iv）。
**试过并回退**：首末行中心内移 L/2（理论更省一条行）→ 覆盖率实测下降：norim 300×300 侧壁
97%→91%（缺口 max 29→67mm）、cao 面2 100%→69%。省行程不能拿漏喷换，已回退并留注释。
**验证**：残白 row=60/150 → 1 条居中行 248mm（板 242）；row=12 → 4 行全沿长边、连续喷 944mm。
全量回归（14 用例）：行数与改前一致，仅 complex 面3 行方向 0°→4.7°（行数 7→4、行均长 329→358）；
face_cover 覆盖率持平或更好（complex 全 100%，norim 面1 99.3→99.7%，cao/bin 不变）。
