### 三处改动（均带注释说明取舍，`cpp/SprayTrajCore/spray_traj.cpp`）

1. **`build_plane_mesh` 新增 `loopsOut` 形参**：把三角化用的轮廓多边形 `poly`
   （已挖孔、已桥接）回传给调用方，存进 `planeLoops[segIdx]`；同时在 PCA 基变换处
   统一到 `(uu,vv)` 口径（`uf=uu*ca+vv*sa`），避免与行坐标差两层旋转。
   集中存储新增 `planeLoops / planeBaseC/U/V / planeFrag`（索引 = segs 下标，不是 wi）。

2. **keepMask 回筛去掉 `kept >= inl/2` 守卫**（原 `spray_traj.cpp:4847` 附近）。
   该守卫本意是怕形态学削光好面，但在"面本身是稀疏过渡带"时必然失效：面0 只保住
   37%，条件不成立 ⇒ 碎片点原样布行 ⇒ 按分位包围盒张开。改为无条件按掩膜回筛
   （`kept>=20` 兜底）。**试过但否决的两个判据**：
   - 覆盖率 < 12% 丢面：误删 curved 真实面（7,429 点散在 145,386mm²，覆盖率 6.9%）；
   - 连通块最大块 < 60% 丢面：同样误删 curved 面1（3 块、最大 53%）。

3. **布行后按重建轮廓修正行**（新增 `clipRowByLoops`，在 `ringMode` 判定之后）。
   分两档：
   - 正常面：只对"轮廓/行 < 40%"的夹端点（`SPRAYTRAJ_NO_ROWCLIP=1` 可关掉对照）。
     门槛 40% 的依据是实测：complex 面1=91%、面4=91%、cao 面0=97%（边界误差），
     出框面是 5~35%。
   - 碎片化面（重建网格碎成多块且最大块 <= 50%，`planeFrag[]`）：逐区间切段。
     bigplane 面0 正属此类（3 块、最大 40%）。
   **否决的方案**（都会漏喷或碎化，勿再试）：
   - 无条件夹端点：`SPRAYTRAJ_ROWCLIP_DBG` 诊断显示 complex 面1 夹掉 1091mm 里 58%
     有材料支撑、面4 是 67%、cao 面0 是 94% —— 点云有料，只是轮廓被开运算缩了；
   - 按轮廓一律切段：norim 行数 195→268、zhe 面1 行数 5→2；
   - `gapSeg` 从 `max(fillHole,L*0.5)` 改为 `max(L*1.2,20)`：norim 行数 195→864、
     longstripe 47→113（线扫点云沿行 40~80mm 点间隙是常态，不是真空）。
