## 诊断：开口盒没有内壁/外壁概念，法向定向只有一条全局规则

用户提问「开口的盒子你是怎么识别法向的，不应该分为内壁跟外壁嘛」→ 确实是缺陷。

**现状（spray_traj.cpp 三处）**
1. `CloudNormals::build`（1044-1086）：KNN=25 的 PCA 法向，**符号随机**（无向）；
   2 轮保边平滑的保边判据用的是 `fabs(dot(nor[j],nor[i]))`（1077）——
   用绝对值意味着「反向」也被当成同向，薄壁内外两层法向会互相抵消。
2. 面块定向（3385-3406）：唯一规则
   - `|n.z| > 0.05` → 强制归 +Z 半球；
   - 否则（近竖直）→ `dot(n, c - partC) < 0` 就翻，即**背离整件质心**。
3. 合并阶段的 `orient` lambda（1636-1655）用同一口径算「有向夹角」判同面。

**这条规则隐含假设**：工件是凸的、只有外表面、质心在材料内部。对开口盒的**内表面**
（可喷侧朝盒内）恰好全反；对倾斜内壁（|nz|>0.05）会被强行拉成朝上。

**实测**
- `box.ply`（34580 点，x 0~400 / y 0~300 / z 0~300，z=300 只有 354 点 = 无盖，
  即扫描的是**盒内表面**）：分割出 5 面 ✓，但主面（y=300 壁）质心 y=300、
  定向后法向 **+y（朝外穿墙）**，正确应为 -y；四面壁按「背离质心」全部朝外。
  日志里 `[split] 侧壁面` 打印的是定向**前**的随机符号，不能用来判断最终朝向。
- 合成薄壁盒 `/e/tmp_build/thinbox.ply`（60k 点，壁厚 4mm，内外各 5 面，噪声 0.15mm）：
  - 直接判成**曲面块**（点间距 3.77mm、拟合半径 15.1mm），面片0 一个块吃掉 41965 点 = 62.5%；
  - 10 个真实面只分出 6 块，侧壁每面只剩 1100~1270 点（应 ~7500）；
  - 侧壁法向出现 `+y,+y,+x,-y,+x`：同轴向两层被翻到同一侧，**无法区分内外壁**。
  - 合并判据 `hCap=6mm`（1669）在壁厚 <6mm 时会把内外壁并成同一块，
    且定向后夹角=0，合并门槛完全挡不住。

**后果**：抬升沿法向 → 喷头落到材料外侧/壁内（standoff 30mm 就是 30mm 错位）；
覆盖率统计仍可能显示 100%（面块已合并）；碰撞判据基于错误法向；
内角（内壁∩内底，凹）与外角（外壁∩顶沿，凸）的过覆盖方向相反，不能共用一套。

**方案（待用户拍板，未实施）**
- 主推：体素化（1~2mm）+ 从边界 3D 洪泛，把自由空间分成「外部连通域」和「腔体连通域」，
  面点法向指向其相邻的自由体素；薄壁两侧都自由时，用连通域 label 区分为外壁/内壁。
  顺便得到开口方向、腔体深度、喷枪可达性。400×300×300 @1.5mm ≈ 450 万体素，成本可接受。
- 备选：法向射线自由空间（沿 ±n 打射线，取 `d_free` 内无点的一侧）——对厚壁够用，
  薄壁两侧都在几毫米内撞点，判不了，需配合多层穿透计数。
- 视点定向不可用：扫描仪在盒外上方，内壁可喷侧恰恰背离视点。
- 顺带要修：平滑的 `fabs(dot)` → 有向 dot；`|nz|>0.05` 强制 +Z 对斜内壁是错的。

实验脚本：`E:/tmp_build/thinbox.py`（生成薄壁双层盒）。

## 追问「为什么外壁给了内壁不给」→ 找到内壁整层消失的根因并修好

**根因（不是输出被过滤，是内壁从来没有成为独立面块）**
`split_planes` 的法向区域生长判据在 spray_traj.cpp:1322 用的是
`fabs(dot(nor[j], sn)) >= cosGrow` —— **无向法向**。薄壁内外两层法向相反（180°），
`fabs` 后夹角=0°，被判成同一张面直接合并。块质心因此正好落在两层中间。

铁证（thinbox，壁厚 4mm）：面块质心 y=298.0（两层在 296/300）、x=397.7（396/400）、
y=2.3（0/4）；沿轴向直方图是 4mm 间隔的双峰。

合并后射线两侧各走一个壁厚就撞到对面层 → `freePlus≈freeMedium≈3.5`，
三态分类得到 `cp=cm=0`（两侧都贴材料）→ 代码走 `else fo.isInner = 0` → **全部标成外壁**。
所以界面上 6 行全是"否"，内壁一个都没有。

**修法（只动输出层，不动 segs，轨迹逐字节不变）**
1. `classify_face_orientation`：`cp==0&&cm==0` 从"兜底(src=2)"改为独立态 `src=4`，
   `isInner=-1`（未分），不再默认 0 当成外壁。
2. `SprayTrajPlane` 槽位 8 → `SPRAYTRAJ_PLANE_SLOTS 16`（6 块拆完要 12 行，8 会截断）。
   ABI：Plane=18648 / Point=64 / **Result=298488**（原 149304）；Native.cs SizeConst 8→16。
3. `res.plane_count` 之后新增拆层段：对 `src==4` 的块，按 `h=dot(p-c0,n)` 的符号把点分两片，
   各自算质心；**离 partC 更远的一片 = 外壁**（法向 `norm(cOut-partC)`），另一片 = 内壁（取反）。
   外壁行复用原行（保留 poly 网格不重复渲染），内壁行追加、`polyVertCount=0`。
4. `planeSeg[]` 记录 `res.planes[wi]` → `segs[i]` 的映射（wi 只在实际出网格的面自增，两者不同步）。

**验证**
- thinbox：6 块 → **12 行（6 外 + 6 内）**，x/y 四壁内外法向全部相反且朝向正确
  （外壁 y=300 → +Y，内壁 y=296 → −Y；外底 z=0 → −Z，内底 z=4 → +Z）。
- box.ply（单层）：仍 5 行、全"内/射线"，未被误拆。
- 回归 8 样本轨迹点数与上一版完全一致：box 11788、bin 1711、cao 1601、complex 4931、
  curved 2659、longstripe 11472、zhe 1845、tray 1288。
- bin.ply（真实件）也会触发拆层：2 个薄壁块拆开（面0 外 −Z / 面3 内 +Z）。

**仍然遗留（下一步要做就动这里）**
- 1322 行的 `fabs(dot)` **根因没修**。现在只是事后拆层，分割依旧把两层并成一块，
  薄壁件的覆盖率、行端口径、面片重建都还建立在"一块两层"上。
  真要修得先做符号一致性传播再把区域生长改成有向 dot —— 会动所有样本的分割结果。
- 拆层判内外用"离 partC 更远=外"，对凹陷/复杂件不成立（薄壁壳一般 OK）。
- 曲面块（thinbox 里 41965 点那块）也被拆了，但块本身是混合的，拆出来意义有限。

产物：`outputs/thinbox_faces.csv`（12 行拆层样例）、`outputs/wpf_faces.png`（界面取证，已更新）。

## 追问「这么完美的平面怎么重建成这样 / 轨迹还残缺」→ 假曲面块才是元凶

**根因不在显示，在"整件被判成一个曲面块"**
`patch_is_polyhedral`（spray_traj.cpp:3255 附近）用 `nmax=8` + 覆盖率 `coverReq=0.93` 做
多平面校验。薄壁盒有 **10 个面（内外各 5）**，8 个平面只盖 85.2% < 93%，
于是 86.2% 的点（57928/67182）被当成"曲面块"，用 **cell=21.8mm 的粗网格**去拟合一个
400×300×300 的盒子 —— 面片就皱成一片多边形；同时该块走曲面路径后
`[曲面] 行追踪失败，跳过该块`，**整块没有轨迹**，这就是"轨迹残缺"。

**修法（不能简单调低覆盖率门限）**
调低 0.93 会把 sag 30mm 级的缓曲面（切成 12 个薄带就能盖 95%）误判成多面体。
改用"法向成对"判据：闭合多面体的平面法向必然成对出现（±X/±Y/±Z），曲面薄带的法向是
单向连续铺开的。给 `patch_is_polyhedral` 加可选出参 `planeN` 收集各平面法向，然后
`np>=3 && cov>=0.75 && 反向平行对 >= 2` → 判定多面体、退回平面分割。

**拆层判据也改了（上一版依赖射线 src==4，不稳）**
射线从块内混合两层的点出发，采样位置不同结论就不同：5 块里只有 1 块得到 src=4，
另外 4 块被误判成单侧材料。改成纯几何判据：把点沿块法向投影、排序后找最大间隙，
`maxGap >= 1.5mm` 即为双层。**必须剔除排序后首尾各 30 个点**——边缘离群点的间隙
（实测面0 落在第 2 个点、面2 落在倒数第 1 个点）比真正的层间间隙还大，会把判据带偏。

**法向符号**：只能用块自身拟合法向 `n`，符号由"哪层在外"决定（`hiIsOuter ? n : -n`）。
不能用 `norm(cOut-cIn)`：两层虽平行但点集面内分布不同（边缘缺失/残点归并不均），
质心差里混着面内偏移，会带出 12~15° 假倾角；也不能用 `norm(cOut-partC)`，同理。

**结果（thinbox，壁厚 4mm）**
- 5 个面片全部"顶点=4 三角=2（规则轮廓）"= 完美矩形，rms 93.211 → **2.006**
- 面级清单 **10 行（5 外 + 5 内）**，法向精确：(0,±1,0)/(±1,0,0)/(0,0,±1)，angZ 精确 90/0/180
- 轨迹 11227 → **11740 点 / 125 行**，5 个外表面全覆盖（枪位 x=−98/498、y=−98/398、z=102，
  正好是 standoff=100），每面 1949~2625 点
（注：分析 bbox 时要看 p1/p99，极少数离群点会把 min/max 拉到 ±200mm 外，看着像轨迹发散。）

**回归 8 样本**：轨迹点数与上一版逐一相同（box 11788、bin 1711、cao 1601、complex 4931、
curved 2659、longstripe 11472、zhe 1845、tray 1288）。`curved.ply` 仍走曲面路径（未被新判据误伤）；
box.ply 仍走原来的覆盖率路径（99.9% 达标）。

**遗留**
- 轨迹只喷**外表面**（5 个朝向），内壁 5 个面**没有轨迹**。要内壁也喷，得把 `n0` 接进
  standoff 计算，并处理内壁进刀方向（枪体不能穿对面壁）——这是下一步，会改所有样本的轨迹。
- 曲面分支没有拆层逻辑（`src==4` 的拆层只对平面块生效）。
- 新判据若遇到"弯曲板的正反两面都被扫到"这类件，可能误判成多面体；届时看 `curved.ply` 类回归即可发现。
- 调试探针 `[layer]` 走 `SPRAYTRAJ_FACE_DBG` 环境变量，正常输出不受影响。


## 11:30 面级清单角度窗口 + 修掉 i<8 截断导致"内壁不显示"

**用户口径**：面法向与 +Z 夹角 -130~130 都要列出；开口盒除底面（朝下）外，其余面全列。

两处都改成 `SPRAYTRAJ_PLANE_SLOTS` / `res.planes.Length`。

拆层行同时补上 `nx,ny,nz`（理想喷距方向），之前 memset 后是 0。

**界面**：内壁橙色 / 外壁蓝色（fill+轮廓线都改色）；面列表上方加 `TxtFaceStat`

**实测**（thinbox 400×300×300 壁厚4）：

**遗留**：轨迹仍只在外表面（内壁 4 面 + 内底无轨迹），需把 n0 接进 standoff。

## 11:45 内壁轨迹：拆层从"输出行"下移到 segs

**做法**：拆层原来只改 `res.planes`（输出行），轨迹按 `segs` 生成，所以内壁永远分不到轨迹。
现在在 `gen_trajectory` 里，法向定向 + 主面统计之后、`meshOk` 声明之前，把每个双层块
拆成两个独立 `PlaneSeg`：外层 `pl.n = nOut`（离 partC 远的一片）、内层 `pl.n = -nOut`（朝腔内），
`pl.c` 各用层质心，`pl.d = -dot(n, c)`。拆完全部外层排前、内层排后，避免枪在工件内外交替穿。
判据仍是"沿块法向投影的最大间隙 ≥1.5mm 且两侧各 ≥30 点"。

**新问题：内壁枪位在内腔，角落会顶到相邻壁**
- 内壁轨迹两端各约 4mm 宽、最深 2mm 侵入相邻壁
- 更糟：内壁首点贴壁时，面间过渡的"从安全高度垂直下降"整段穿墙（实测 423mm 直线穿 300mm 壁）

**修法**：枪位可达性过滤。面点沿法向抬 standoff 得到枪位，查枪位到点云最近距离，
< gunClear(=max(12, 0.2*standoff)=20mm) 的面点不参与布行。只对 `fo.isInner>0` 生效
（外壁枪位在件外，最近点必然 ≥standoff）。`keep.size()<20` 时不替换，防止整面删光。

**实测（thinbox 400×300×300 壁厚 4）**
- 5 块 → 10 段，每面 21~25 行，轨迹 11740 → 20946 点
- 枪位簇：外壁 x=-100/500、y=-100/400、z=-100；内壁 x=104/296、y=104/196、z=104 全部正确
- 穿材料段 0（改前 223 段：222 段行内角落侵入 + 1 段 423mm 空移穿墙）
- 内壁覆盖收到 x∈[24,376]、z∈[27,291]；外壁/外底仍满覆盖

## 12:05 gunClear 参数化（枪体安全半径可填）

原来硬编码 `std::max(12.0, 0.2*standoff)`（standoff=100 时=20），现改为 `SprayTrajParams.gunClear`。
`gunClear <= 0` 时回落到原表达式，保证旧调用方（不填该字段的宿主）行为不变。

- 语义：喷头（枪帽/旋杯）端面到障碍物的最小允许距离 = **喷头外径/2 + 安全余量**
- 默认 20mm（枪帽 Ø32 半径 16 + 余量 4）
- 链路：C++ 结构体（尾部加 double，ABI Params 由 96→104）→ driver `-gc` → C# Native.cs →
  界面新增「枪体安全半径 (mm)」输入框 + CLI `--gc`
- 由于是尾部追加且 int 后原本有 4 字节 padding，C# 顺序布局自动对齐，两侧 size 一致

**覆盖实测（thinbox 400×300×300 壁厚 4，几何关系内角让位 ≈ gunClear + 壁厚）**
| gc | 行数 | 点数 | 内壁 y 面 x 覆盖 | 穿材料段 |
|---|---|---|---|---|
| 20 | 234 | 20946 | [23.9, 376.1] | 0 |
| 30 | 229 | 20081 | [35.6, 364.4] | 0 |
| 40 | 221 | 19057 | [44.0, 356.1] | 0 |

规律：内壁在角落必须让开 ≈ gunClear，覆盖率与 gc 直接反比；gc 再大也不会穿壁（只是少喷边带）。

**回归**：8 样本默认 gc=20 与改前逐一相同。顺带纠正一处历史记录错误——
`curved` 一直是 2660 点，此前日志里写的 2659 是陈旧值（用 git stash 回滚源码重编对照确认）。
