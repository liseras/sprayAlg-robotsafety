## 修复

`split_planes` 末尾新增**终局同面合并**（在"连续曲面合并"之后、最终排序之前）：

```
① 有向法向夹角 <= 15°      （orient(): 先 +Z 半球，近竖直背离质心；防薄板双面法向相反）
② 小块点到大块平面的 |h| p95 <= 6mm
③ KNN 图里有边横跨两面（相邻；排除同平面孤岛）
④ 并后重拟合 RMS <= max(flatnessTol, 8mm)
```
标定开关：`SPRAYTRAJ_MERGE_ANG` / `SPRAYTRAJ_MERGE_H`；`SPRAYTRAJ_DUMP=1` 打 `[dbg] 同面候选/同面判距`。

为什么不动已有的 8° 连续合并：8° 是硬门限（坑表 4：25° 会吞折型板 13.2° 折边）。
新规则用"距离极近"换角度余量，专治扫描条带切碎窄面。

## 新坑（已写进 HANDOFF 37/38）

37. "法向接近"必须用**有向**夹角，`fabs(dot)` 会把薄板上下两面（法向相反）当 0° 并掉。
38. 现场扫描条带切碎窄面时角度会略超 8°；用"距离换角度"。距离判据用**点高度**，不能用平面偏移差
    （折边两面共线、偏移差≈0）。
