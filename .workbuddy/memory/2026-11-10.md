## 诊断：生成层为何出现 ~180° 法向（反法向面）

结论：+Z 半球只是 `split_planes` 的**初始定向**（spray_traj.cpp:3708-3729），最终上报/使用的是"可喷侧" `fo.n`。
后面有三处**刻意取反**：
- 内壁朝腔翻转（:3742-3756，仅 src==1 && isInner>0）
- 薄壁双层拆段（:3936-3978，src=4，内壁法向 = -nOut）
- 薄壳双面（:3997-4039，src=5，shellThick>0 时默认关闭）

用户看到的相反法向对全部来自 src=4（薄壁拆层）：
- A_raw（相机系）：面2 angZ=13.06° / 面6 angZ=166.94°，n 严格互为相反数，layerThick 均 33.40；沿法向间距 22.3mm、横向错开 154.8mm，点数 1989 / 46472
- B_base（基座系）：面0 angZ=86.09° / 面5 angZ=93.91°，同上；间距 44.6mm、横向 63.5mm，点数 53727 / 86209

判定：**很可能是误拆**——真薄壁两面应只差一个壁厚(1~5mm)且 footprint 重合；这里差 22/45mm、横向错开 150/63mm、面积悬殊。
根因：拆层"判据一"（沿法向最大间隙 maxGap>=1.5mm，:3848-3863）**没有厚度上限**，台阶/两级平台与"壁的两侧"在几何上无法区分；
"少侧覆盖 25%"（:3892）只比包围盒边长比，不比重叠率，挡不住。

后果：A 里面6 的 166.94° > 130° 窗口 → 46472 点（约 16%）整面不布行；B 里 93.91° 落在窗口内 → 该面被"从背面"喷。

待改（未实施）：
1. 判据一加厚度上限（如 `maxGap <= max(2.5, 3×壁厚先验)`，或要求两片各自的平面 RMS 很小 + 间距 <= 5mm 才算壁）
2. "少侧覆盖"改真实 2D footprint 重叠率（栅格 IoU），不用包围盒边长比
3. 拆出的内壁若 angZ 落入 130°~180° 死区，回落为"同向两面"而不是硬取反

验证入口：`SPRAYTRAJ_FACE_DBG=1`（打 [split] seg 双层 间隙=..），面上清单 `<out>.faces.csv` 看 sideSrc / isInner / angZ / inWin 四列。

## 17:50 诊断：姿态为什么会贴关节限位（J5）—— 结论与方案C的前提修正

诊断报告：`outputs/diag_关节限位_J5_2026-11-10.md`，脚本 `temp/_lim_ana.py` / `_enum2.py` /
`_gain.py` / `_degen.py` / `_base.py` / `_tilt5.py` / `_drift.py` / `_branch.py`（只读 CSV）。

**实测定位（9 个算例的 trajectory_checked.csv，按 kJoints 的 lo/hi 算余量）：**
- 瓶颈几乎总是 **J5（±120°）**：big −5.2°、longstripe −12.2°、cao/complex/curved ≈1.0~1.2°、longwide 8.0°。
  J4(±270)/J6(±360) 最小余量常是 100~270°，从来不是约束。
- big 的 J1=0.2°、longstripe 的 J6=0.0° 都只是 1~3 个个别点，不成规模。

**⚠ 修正方案 C 文档第 3 节的核心公式（重要，别再沿用）：**
`PROMPT_倾角里程渐变方案C.md` 写 `θ5 = arccos(d_z)`（d=枪轴，世界系）。**实测对不上（差 51°）。**
真关系是 **|θ5| = arccos(u_z)，u = R03ᵀ·g，R03 = Rz(θ1)·Ry(θ2+θ3)**，
即 **|θ5| = ∠(前臂方向, 枪轴方向)**。展开：`u = (cosθ4·sinθ5, sinθ4·sinθ5, cosθ5)`。
验证：big/cao/complex/tray 误差中位 0.001°、p99 0.017°；big 最差点实测 |J5|=125.2° vs ∠(f,g)=125.2°。
结论不变（滚转不影响 θ5），但"改 tilt/az 能改 θ5、换解支不能"这条因果必须按新公式理解。

**换解支救不了（实测枚举 28 个种子）：**
- big 最差点找到 3 支，当前支 margin=−5.23° **已经是三支里最好的**（另两支 −153°/−115°，J1 绕 180°）。
- longstripe 找到 6 支，当前 −12.16° 仍最好。
- big 抽样 400 点：全支最优 − 当前，**中位 −0.00°、p90 0.01°**，Δ>3° 仅 1%。
⇒ **解支多解只体现在"位置/臂构型"层面，腕部余量层面换不出来。**

**真因 1（最关键）：朝上的大平面倾角被强制 0。**
`tiltAxisAndDir`（robot_safety.cpp:1351）用 `|ref − n(ref·n)| < sin5°` 判退化，无基座时 ref=重力+Z（:1867）。
big 枪轴与 −Z 夹角中位仅 3.9° ⟹ **退化率 100% ⟹ tilt 恒 0、az 只有 0 ⟹ 唯一活着的杠杆全关**。
实测 big `tilt_deg` 唯一值 = [0.]、非零点 0/9761。比方案 C 以为的"面组常量"更彻底。
（对照 longstripe 法向偏 36° 不退化：tilt 有 34 个值，但 J5 仍 270 点超限 ⟹ 面级常量照样远端被近端绑住。）

**真因 2：方位是行级单值 + `kAzLimitDeg=60°` 白名单（:2243）。**
实测同一最差点：tilt=0/az=0 → J5=125.2°/margin=−5.23°；
**tilt 0~35°/az=−60° → J5=85~86°、margin=+6.9~8.6°，34 个候选全过。**
⇒ **大平面上方位比倾角更有效**。方案 C 把 C1b（方位渐变）列为"可选、先不做"是**优先级排错**了。

**真因 3（副作用，比贴限位更危险）：解支整体翻转。**
big #7→#8：J5 +125.2 → −108.7（Δ234°）、J1 −36.4 → +143.8（Δ180°），肘上↔肘下整体换构型。
longstripe 更严重：相邻点最大关节步长**中位 179.85°**、11514 个点对 >5° ⟹ 整条轨迹都在换构型。
建议单独立项，与贴限位分开治。

**建议顺序（与方案 C 的 §8 顺序不同）：修退化 → 展开方位 → 再做里程渐变。**
不先修退化，big 这类件开 bit2 也仍然无效。

**待用户确认（3 条会影响改法方向）：**
1. J5 余量下限（现 jointMarginMin=1.0°）是否提到 10~15°（会立刻多报 JOINT_LIMIT，是如实报）。
2. **平放件（big）工艺上是否要求正对 +Z 喷**——若是，则 tilt 恒 0 是正确行为，修退化反而做反。
3. 方位能否放开到 ±60° 以外（实测需 −60°，正好卡边界；放到 ±90° 余量还能涨）。

另注：`valid()`（:608）的"不限位"是**布尔** `!s.over`，"余量 0.5°"与"余量 80°"同分，
margin 只是 rankCmp 第 4/5 顺位的 tie-breaker；有 seed 且 maxJointDelta≤10° 时更会**立刻 return**（:623）不跑其余 27 个种子。

## 23:xx 实现 `RS_POSE_TILT_J5`（逐点解析救 J5）—— **叠加层**，A/B 通过

**用户口径**：「不能定死姿态，一个面的姿态也是可以变的」。按此实现 bit2 模式。

### 核心设计判断（唯一真正的坑）

**J5 必须是「叠加层」，不能是「另一套姿态方案」。**
第一版写成阶段 2 头号分支（危机点解析解、非危机点一律 tilt=0）→ 用局部修补推翻整套基线，三个算例退化：

- longwide 新增 7 点超限（基线 2.81° 抬出浅槽）

改成叠加后副作用**全部消失**。

### 最终架构：新增「阶段 3.6」（robot_safety.cpp，阶段 3.5 之后、过渡点抬升之前）

  （longstripe 27 个退回点里 clr=−20.9mm 占一半）。解法：保持倾角、方位扫 ±40/±75/±110/±145°，
  找第一个过 hardOk 且 θ5 变小的 → longstripe **25 点靠这层救回**。
