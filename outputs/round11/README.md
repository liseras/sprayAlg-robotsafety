# 第十一轮 UI 验收：曲型板"轨迹看着乱"的定位与修复（枪姿连续性）

用户反馈：**"重建很好，但是这轨迹显然不规则啊，乱七八糟"**。

## 结论先说

乱的是**枪位**，不是行：行点横向漂移 ≤1.6mm、步距恒 4.00mm、14 行在平均面内是直线。
CSV 里的点是 **枪位 = 面点 + 100mm×法向**，100mm standoff 把逐点法向的 1~2° 噪声放大成
1.75~3.5mm 的横向抖动，行端换墙/折边处单步转 15~30° 时枪位单步甩 10~50mm。

修复（只动 `rowN`，位置一字不动）：行内 `[1,2,3,2,1]` 低通 ×4 遍 + **双向角速率限幅 6°/步**。

| 指标 | 改前 | 改后 |
|---|---|---|
| 枪位二阶差分 RMS | 3.29mm | **1.29mm** |
| 最大单步 | 51.1mm | **12.9mm** |
| `>8mm` 的步 | 222 | **106** |
| 单步法向摆角 >15° | 31 处 | **0 处** |
| `seg_mean` / `seg_max` | 5.875 / 27.352 | **5.685 / 12.897** |
| 覆盖率 / 贴合残差 / rms | 92.2% / 8.88mm / 8.878 | **完全相同** |
| 9 个非曲面样本 MD5 | — | **9/9 IDENTICAL** |

## 端部为什么还有"折返/钩子"（不是 bug）

工件左端是陡壁（法向与平均法向夹 80°）、右端是折边 + 平台（40mm 内法向转 55° 以上）。
枪位在面外 100mm，**凹折处的等距偏置面必然自交**（折边曲率半径 ≪ standoff=100mm），
所以每条行在端部都会折回一小段。这是"法向跟随 + 固定 standoff"的固有结果，三条路的取舍见
`HANDOFF_交接说明.md` 6.4⑥（A 保持 / B 折边处分行 / C 收紧限幅）。
