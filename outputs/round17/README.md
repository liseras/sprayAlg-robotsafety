# 第十七轮：空移太长、轨迹被切成太多段

用户原话：**"为什么不是连续的，而是分这么多段呢，喷枪抬上抬下很费时间"**

样本：`cpp/_regress/bin.ply`（垃圾桶/截锥，43469 点），默认参数（standoff 100mm、200mm/s）。

## 一句话结论

三个判据都写错了维度：

| # | 判据 | 错在哪 | 改成 |
|---|---|---|---|
| 1 | 面间过渡"要不要抬到安全高度" | 用**端点 z** 推断整条直线是否安全。锥面顶 z=231.9 vs 门限 241.1，**只差 9mm 就漏判** | `segClearOK(a,b)`：沿直线采样、逐点查 KD 树最近工件点，全程 ≥ `max(6, 0.25·standoff)` 才直连 |
| 2 | 安全高度取多少 | `zPartMax + 2×standoff`。但枪位 z ≤ `zPartMax + 1×standoff`（因为 \|n_z\| ≤ 1），多抬了一个 standoff | `zPartMax + 1.3×standoff`（仍留 30mm 余量） |
| 3 | 这一段要不要关枪 | 用**面点跳距** `d <= 3L`。但枪位 = 面点 + standoff·n，法向旋转会把大跳距在枪位上抵消：L=12 时面点跳 **93mm**、枪位只走 **13mm** | 用**枪位行程** `dg = \|(b+nb·so)−(a+na·so)\| <= 3L`；平面路径跨段统一成 `gap > max(turnR·3, 3L)` |

## 结果

| 工况 | 总长 | 空移 | 空移占比 | 喷涂段（关枪次数+1） |
|---|---|---|---|---|
| `-row 30` 改前 | 4276mm | 1045mm | 24.5% | 4 |
| `-row 30` 改后 | **3603mm** | **340mm** | **9.4%** | **3** |
| `-row 12` 改前 | — | 1178mm | — | 11 |
| `-row 12` 改后 | — | **499mm** | — | **4** |

3 段 = 锥面 / 顶环 / 内腔底面。这三个面本来不连通，已是理论下限。
剩下的 2 处空移是必走的（锥面顶→顶环 118.6mm、顶环→内腔底面 221.1mm，都是直线）。

其余样本空移同步下降：cao 1853→1002、complex 3934→2773、zhe 1276→933、
box 5106→4546、curved 1442→1302、tray 698→687（mm）。

## 安全性

`E:/tmp_build/verifyclear.py` 独立复算（不用 C++ 里那套判据，直接算空移段到点云的最近距离）：

- 锥面→顶环：最近 **81.2mm**
- 顶环→内腔底面：最近 **34.4mm**，且这个最小值出现在**落点**上 ——
  落点本身是正常喷涂点，其离点云的距离就是 34.4mm（喷涂点中位 99.2mm、p1 32.2mm、min 29.7mm）。
  也就是说这条过渡并不比正常喷涂更贴件。

## 回归

28 个样本。**喷涂层点集全部是超集关系、位置逐字节不变**（只有 spray 标志翻转）；
变化的只有过渡段航点（每处删 3 个、加 1 个中点）。
`rms` / `seg_mean` 全同，bin 的 `seg_max 4.840→3.996`（原来的 4.84 是插值出来的假点距）。
