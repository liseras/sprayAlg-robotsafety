用「枪轴 vs 落点处**真实局部法向**（K=25 PCA）」算实际喷角：

|---|---|---|

- 超工艺上限 30° 的点：**1226 / 3734 = 32.8%**
- 超 45°：15.7%　超 60°：7.1%

而 `tilt_deg` 全表只有 **0°(1835点) / 10°(834点) / 25°(1057点)** 三档，max 25°。

**台账与实际的差**：中位 14.2°，p95 62.2°，max 87.9°。

## 二、两个独立的成因

### 成因 A：`tilt_deg` 的参照系是「面拟合法向」，不是局部法向

`robot_safety.cpp:1440`

```cpp
pr.sprayAngle = angleBetweenDeg(d, n);   // n = t.normal(i)，取自面级拟合
```

而 `n` 在面级常量模式下是**整面一个法向**。侧板被拟合成一个平均平面后，其法向与板上每一点的局部法向并不一致 —— 实测这些斜面上点的局部法向从 10° 连续分布到 35°，而面级只取了一个代表值。

所以：
- 记录 25° ← 枪轴与**平均法向**差 25°
- 实际 88° ← 枪轴与**该点真实法向**差 88°

这不是记录 bug，是**参照系选错**：工艺关心的膜厚取决于枪轴与**落点局部曲面**的夹角，不是与一个被平均掉的法向的夹角。

### 成因 B：面级常量姿态让侧板整片歪一路

原始轨迹（未修正）喷点姿态只有 **6 个离散 IJK 档位**：

```
IJK=(+0.035,+0.065,-0.997)   988 点   偏 2.5°
IJK=(+0.023,+0.072,-0.997)   843 点   偏 2.7°
IJK=(+0.385,+0.069,-0.920)   676 点   偏 21.8°   ← 面4
IJK=(+0.198,+0.016,-0.980)   650 点   偏 10.5°
IJK=(-0.358,+0.061,-0.932)   393 点   偏 22.1°   ← 面5
IJK=(-0.193,+0.118,-0.974)   190 点   偏 13.2°
```

面内**绝对不动**，换面一次甩 22°。您截图里那段明显倾斜的轨迹就是这两片 21.8°/22.1° 的侧板。

同时 `needTilt` 的公式是：

```cpp
t = p.tiltNonUpDeg * (alphaDeg / 90.0);   // tiltNonUpDeg=60, tiltMaxDeg=60
```

即"法向与 +Z 偏差越大，倾角给越多"。对侧板 α≈22° → 需求 14.7°。但面级择优会因为"可解性/间隙"把它抬到 25°（`tiltStepDeg` 网格），于是**倾角大于几何需求**。

## 三、点云本身是"连续曲面"，不是几块平面

全点云局部法向与 +Z 夹角分布（残差全部 <1.5mm，即都是局部平整的好点）：

```
  0~ 5°  6.9%      20~25° 14.0%
  5~10° 14.6%      25~30° 10.6%
 10~15° 15.0%      30~40° 13.5%
 15~20° 15.7%      40~50°  6.4%
                   50~90°  3.3%
```

**一路连续铺到 40°，没有断档。** 真正竖直的壁（>70°）只有 2365 点（0.8%）。

这说明这个工件的主体是一张**缓变的曲面/钣金拉伸件**，不是"几块平板 + 台阶"。把它切成 7 个平面各自给常量倾角，从根上就不合适 —— 这也是上一轮诊断里"面又碎又多"的另一面表现。

## 四、结论：改哪里

### P0 · `tilt_deg` 换参照系（报数可信）

`robot_safety.cpp:1440` 的 `n` 改成**落点处的局部法向**（用已有的 KNN 邻域现算，或复用 `t.normal` 但那是面级的，不能用）。

否则报告永远显示"最大倾角 25°"，而实际喷角已经 88° —— 安全评估的 `maxSprayAngleDeg=30°` 判断也会因此失效：**它现在判的是"枪轴 vs 面法向"，不是"枪轴 vs 真实曲面"**，属于假通过。

这条是**安全性质**的问题，优先级最高：`verdict=REJECT p0=93 p1=563` 里那 563 个 P1 告警，很可能就是被这个问题掩盖了实际更大的喷角超限。

### P0 · 侧板不要用面级常量姿态

成因 B 的 22° 是纯几何造成的（面法向本身就偏 22°），无法靠调倾角系数消除。只有两条路：

1. 开 `--tiltmode 1`（逐点连续），让倾角严格跟该点法向走 → 侧板会自然倾斜而不是"被选择成 25°"
2. 或者承认这是曲面件，走曲面块路径（`gen_surface_rows`）而不是拆成平面

### P1 · `tiltNonUpDeg=60` 对本案偏大

侧板 α=22° 时几何需求只有 14.7°，但系数 60 让上限到 25°（网格档）。若工艺品允许，`--tiltk 30` 能把需求压到 7.3°。

**但这会把枪往工件里怼**（`tiltNeedDeg` 的注释写明：δ 越大倾角越大是为了让腕部够得着）。实测 `--tiltk 1` 结果完全不变（p0=93 p1=563 tilt=8/25/25），说明本案的倾角不是被 `tiltNonUpDeg` 决定的，而是被**面级择优的可解性/间隙打分**顶上来的 —— 所以改系数无效，必须走上面 P0 那条。

### P2 · 面级择优的 `tiltStepDeg` 网格太粗

`cand` 从 `need0` 起按 `tiltStepDeg` 递增。若 `need0=14.7`、step=6.9，则候选是 14.7 / 21.6 / 28.5…，没有 20° 附近。择优取到 25° 实际是 21.6→网格化后的值。建议网格在 `need0` 附近加密，或直接用 `need0` 不向上取整（既然 `needTilt` 已是连续公式，再网格化只是重新引入台阶）。

## 六、需要您确认

**侧板那 22° 的倾斜，工艺上是要的还是不要的？**

- **要**（侧壁必须斜着进枪，否则喷不到根部）：那当前姿态是对的，问题只是 `tilt_deg` 报小了 → 只改 P0 第一项
- **不要**（应该垂直打）：那这件的分面本身错了，得走曲面路径重做 → 改 P0 第二项

另外 `maxSprayAngleDeg=30°` 这个工艺上限，是按"枪轴 vs 平面法向"定义的，还是按"枪轴 vs 真实曲面"定义的？如果是后者，现在的安全评估结论（REJECT p0=93/p1=563）需要重新跑一遍才能信。
