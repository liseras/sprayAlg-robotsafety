## 2. 方法与口径

### 2.1 倾斜 = 绕表面点做球面旋转（喷距不变）

```
d(θ) = Rot(axis, θ) · n            # axis 在 n 的切平面内、指向「上」
TCP  = face + standoff · d(θ)      # face 是原始面点，不随倾斜移动
⇒ |TCP - face| ≡ standoff           喷距严格不变，变的只有喷角 θ
```

每点都实测 `standoff_err`，见第 1 节「喷距保持最大偏差」。本轮最大偏差 0.000000mm（浮点级，非近似）。

### 2.2 倾角决策顺序（最小修正）

1. 基准倾角：法向偏离竖直超过 45° 的面（侧壁/内壁）给 20°；朝上的面给 0°（工艺最优）；朝下的悬垂面不扳（往上扳会顶穿工件）。
2. 若基准倾角下 clearance < 20mm 或不可达 → 按 5° 步进加大，上限 60°。
3. 仍不行 → 把「上翻方向」左右偏 30°/60° 再试（内壁往上扳可能顶到对面的壁）。
4. 倾角沿行做**只升不降**的限幅平滑（每点 ≤ 3°），保证姿态连续。
5. **但平滑不许把好点变坏**：倾角与间隙不是单调关系（凹槽里倾角越大间隙反而越小），整行统一倾斜方位同理。所以平滑后的位姿一旦比该点自身最优位姿更差，就退回后者，宁可姿态跳一下（见 CSV 的 `tilt_jump_deg` 列）。本轮退回 1 点。
