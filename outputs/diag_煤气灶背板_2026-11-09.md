# 煤气灶背板：小面不合并 + 轨迹只出一小段 — 诊断报告

日期：2026-11-09　　点云：`D:\Code\cloudepoint\点云\点云\喷涂点云_DENSO可达\煤气灶背板.ply`（301334 点，ASCII）

复现命令（行距 80，其余默认 flat=30 / fill=300 / standoff=100 / pt=4）：

```
SprayTrajViewer.exe --ply "煤气灶背板.ply" --row 80 --flat 30 --fill 300 --auto --exit
```

---

## 结论速览

| 现象 | 判定 |
|---|---|
| 小平面不与大平面合并 | **判据挡的是高度差，不是法向差**。真实存在 ~50mm 台阶，物理上不该合并 |
| 轨迹只出一小段 | **70% 的点被"残点归并"以 40mm 容差强行塞给最近平面**，把每个面的轮廓和布行全污染了 |
| 放大合并阈值后轨迹反而更少 | 平面性门（RMS ≤ 0.12×standoff = 12mm）把 17 万点整面判成"误合并"→ 不喷 |

**一句话**：不是合并不够，而是**分面本身是脏的**。合并判据只是把这个脏结果放大暴露出来。

## 一、为什么这些面不合并

从 `SPRAYTRAJ_DUMP=1` 抓到的实际判据输出（`split_planes` 终局同面合并段，L1856–1936）：

```
[dbg] 同面候选: 面0-1 夹角12.7° 相邻=1
[dbg] 同面判距: 面0-1 高度p95=56.74mm      ← 拒绝（阈值 6.0mm）
[dbg] 同面候选: 面0-2 夹角0.8°  相邻=0      ← 拒绝（法向几乎一致！）
[dbg] 同面候选: 面0-5 夹角10.6° 相邻=1
[dbg] 同面判距: 面0-5 高度p95=57.01mm      ← 拒绝
```

合并要求同时满足 4 条（L1849–1853）：同向 ≤15°、高度 p95 ≤6mm、KNN 相邻、并后 RMS ≤max(flat,8mm)。

- **面0–面2 法向只差 0.8°**，唯一挡住它的是「相邻=0」。`相邻` 靠 K=25 邻域边（实测最大跨度 21.9mm），而两面之间隔着 50mm 竖壁 → 必然不相邻。
- **面0–面1 相邻=1、法向差 12.7°（够近）**，但高度 p95 = **56.7mm**，远超 6mm 硬阈值（L1910 `hCap=6.0`，仅靠环境变量可改）。

### 关键：这是真实台阶，不是法向问题

沿主面法向 (0.041,−0.066,0.997) 统计点云高度：

```
跨度 104mm（−55.8 ~ +48.0）
两簇峰位：−24mm（面0/面1/面3 的底层）  与  +20mm（面4/面5/面6 的上层）
```

剖面图 `outputs/_gasback_profile.png` 中，V-H 剖面呈现清晰的**两级平台 + 中间竖直段**。这是燃气灶背板的真实结构（面板 + 边框/凸台），不是扫描抖动。

**所以「法向差不大就合并」这个直觉本身会把台阶件压平**：合并后 17 万点 RMS=16.1mm，远超门限 12mm，`L4693` 判为「疑为误合并/强曲面，不按平面布行」→ 该面**一个点都不喷**。

实测对照：

| MERGE_H | 面数 | 轨迹点 | 结果 |
|---|---|---|---|
| 6（默认） | 7 | 4372 | 7 个面各自布行（碎，但都在喷） |
| 30 | 7 | 4372 | 无变化（p95=56.7 仍超） |
| 60 | 4 | **1142** | 合并成功，但面0 被平面性门拦死 → 轨迹锐减 |

## 二、为什么轨迹只出一小段（真正的病根）

### 2.1 残点归并吞掉了 70% 的点

```
[split] 区域生长: 原始块数=7930
[split] 面块: 6 个（点数 8823 / 35229 / 15157 / 6749 / 6293 / 12409，合计 84660 = 28.1%）
[split] 残点归并: 210201 个点并入最近的平面（容差40.0mm）   ← 占 69.8%
```

`L1730`：`mergeD = max(flatnessTol, curvatureTol) = max(30, 40) = 40mm`

这行代码的本意是「把碎弧段并进去让轮廓扩到真实边缘」，但它**只按点到平面的垂直距离判定，完全不看几何归属**。40mm 容差下，台阶的竖壁、另一层平台的点、甚至侧面掠射点，全被塞给"最近"的那个平面。

后果：
- 面0 拿到 89557 点、重建面积 163042mm² —— 而这只是一个不平整的"平均平面"
- 7 个面片面积合计 451197mm²，按点云采样密度 0.87mm 反推真实表面积只有约 228000mm² → **面积虚高约 2 倍**
- 每个面的轮廓（凸包/规则轮廓）都被拉变形 → `连通块=2~4`、`最大块占比` 低到 39%~49%

这就是您在 3D 里看到的「面又碎又多、形状怪」的直接来源。

### 2.2 面轮廓碎了 → 行也被切断

```
面0: 连通块=1 最大块占比=100%  行数=5  ← 唯一干净的面
面1: 连通块=3 最大块占比=49%   行数=5
面3: 连通块=2 最大块占比=60%   行数=4
面5: 连通块=4 最大块占比=55%   行数=5
面6: 连通块=3 最大块占比=39%   行数=4
```

行距 80 时每面只剩 4~5 行（面尺寸 400~750mm，理论该 5~9 行）。`genRows` 的 `segCnt>=supMin && 段长>=L` 会把碎段丢掉（L4357），连通块越低越容易被切。

### 2.3 覆盖实测（行距 80）

沿主面法向投影按 Y 分带统计点云到最近落点的距离：

| Y 带 | 点数 | 中位距离 | <12mm 比例 |
|---|---|---|---|
| −399.8~−328.2 | 234 | 125.4 | 0.0% |
| −328.2~−256.5 | 1774 | 52.7 | 5.5% |
| −256.5~−184.9 | 29390 | 30.6 | 16.2% |
| −184.9~−113.2 | 31258 | 13.7 | 41.8% |
| ⋯ 中段 8 带 ⋯ | ~30k/带 | 13.7~15.0 | 35~41% |
| 388.3~460.0 | 26366 | 42.2 | 10.0% |

**整体 <12mm 覆盖率仅约 38%**，两端（Y<−250 与 Y>390）几乎是空白。用户看到的"只有一点点"就是这两端 + 台阶过渡带。

注：行距 80 时对角点间距天然 80/√2≈57mm，单看"<12mm 比例"会偏低属正常；但**两端 0~16% 是真的没布行**，因为面轮廓在残点归并后被拉到了不存在的区域。

## 三、改哪里（按优先级）

### P0 · 残点归并必须加几何约束（L1722–1747）

现在的 `mergeD=40mm` 单看垂直距离，是污染源。建议：

1. **加切向距离约束**：候选点投影到该面 2D 域后，必须落在该面已有内点的凹包/重建轮廓内（或距其边界 ≤ 2×点间距），否则不归并。
2. **加法向一致性约束**：候选点的局部法向与该面法向夹角 ≤ 20°，竖壁点就不会被塞进水平面。
3. **容差收到 `max(flatnessTol, 2×点间距)`**，不要用 `curvatureTol`（40mm 是给曲面判据用的，量纲不对）。

改完后预期：面数可能略增，但每个面的轮廓面积与点密度自洽，布行不再被拉变形。

### P0 · 平面性门限的量纲要换（L4689）

```cpp
const double rmsCap = std::max(3.0, 0.12*params->standoff);
```

这行的本意是防"薄壁件整圈壁被吞成一个假水平面"（RMS 85mm）。用 `0.12×standoff` 在 standoff=100 时给 12mm —— 恰好卡在"真实台阶合并后 16mm"之下，导致正确合并被否。

建议改成**与行距挂钩**而非 standoff：`rmsCap = max(3.0, 0.5*rowSpacing)`（行距 80 → 40mm）。理由：平面性该由"喷幅内起伏是否可接受"决定，与喷距无关。行距 80 时 40mm 起伏刚好在搭接容差内。

同时保留现有"假平面"防线：`emax`（最大偏差）另设硬顶，比如 `emax < max(0.5*rowSpacing, 25mm)`，台阶件 50mm 台阶仍会被拦，薄壁 85mm 假面也能拦。

### P1 · hCap 与 standoff/行距解耦（L1870）

`hCap=6.0` 是为"倒角带被切成两条平行窄带"标定的。但它是绝对量，遇到 50mm 真实台阶就完全失效。

建议：`hCap = max(6.0, 0.5*rowSpacing)`。行距 80 → 40mm，仍小于 56.7mm（不误合并台阶），但能救回 6~40mm 的中等错位。**这条单独改不解决问题，必须和 P0 一起改。**

### P2 · 「相邻」判据改用空间距离而非 KNN 索引（L1898）

面0–面2 法向 0.8° 却因 `相邻=0` 不合并。K=25 只覆盖 21.9mm，跨不过 50mm 竖壁属预期。但要区分两种情况：

- 中间**有**竖壁点 → 真台阶，不该合并（当前行为正确）
- 中间**是数据空洞** → 应合并（当前会漏）

建议：加一条补充判据——若两面法向 ≤5°、高度 p95 ≤6mm，且两面**投影域相邻（2D 栅格 8 邻接）**，即使 KNN 不相邻也合并。投影栅格实测占用率 79.1%，最大空洞 56150mm²（约 5.6cm²），这类空洞造成的假断应当能救回来。

## 五、需要您确认的工艺前提

1. **那 50mm 台阶的两层平台，是要一起喷还是本来就该分开喷？**
   - 如果是同一张脸的起伏（比如钣金件冲压凸台），应合并 + 允许 RMS 大 → 改 P0 平面性门限
   - 如果确实是两个独立平面（面板 + 边框立面），那当前分面是正确的，问题只在残点归并污染轮廓 → 只改 P0 残点归并

2. **行距 80 是工艺设定还是试出来的？** 这个件的真实尺寸约 400×860mm，行距 80 意味着整件只有 11 行。若喷幅直径只有 40~50mm，80 行距本身就会漏喷 —— 那是参数问题，不是算法问题。
