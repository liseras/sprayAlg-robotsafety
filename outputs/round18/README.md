# 第十八轮：急转弯（曲率半径）治理

用户问题："**这种急转弯机器人怎么处理的过来呢**"（附 3D 截图）

## 诊断

前一轮的结论是"56 处 >60° 转角、最大 165°"，但那用的是**逐点转角**，指标本身有误导性 ——
圆弧上点距越密，逐点转角越大。换成 **等效曲率半径 r = 段长 / 转角** 才是机器人真正
感受到的量，结果完全不同：

| 指标 | 改前 | 改后 |
|---|---|---|
| 曲率半径 最小 | **0.04 mm** | **0.63 mm** |
| 曲率半径 p1 | 0.23 mm | 1.40 mm |
| 曲率半径 中位 | 19.8 mm | 66.8 mm |
| r < 3mm 的点数 | **514 处** | **65 处（-87%）** |
| r < 5mm | 703 | 76 |
| r < 20mm | 1868 | 263 |
| 步长 < 0.05mm 的点 | 20 | **1** |
| 步长 < 0.5mm 的点 | 570 | **4** |
| 零长段 | 18 | **0** |
| 轨迹点数 | 3856 | 1711（-56%） |
| 覆盖率（工件点到最近枪位） | 中位 67.4 / p99 100.6 | **完全一致** |

## 根因：不是"转弯太急"，是点距坍缩

实测 `bin.ply` 的 idx673~685：**连续 13 个点只走了 1.3mm**（点距 0.03~0.26mm），
坐标在 ±0.05mm 上抖，切向完全由点云噪声决定 → 等效曲率半径 0.03~0.1mm。

机器人其实"看不出"0.05mm 的位置抖动，但控制器的速度规划会把它当成**原地掉头**：
`a = v²/r = 0.04/0.00005 = 800 m/s²`。要么降速到近乎停车（涂层堆积），
要么报位置超差。

为什么不靠圆角解决：横向错开量 δ 只有 0.03mm 时，**任何平滑曲线的掉头半径上限
就是 δ/2**。实测用三次贝塞尔（控制点沿切线放、保证 C1 连续）反而把 `<3mm`
从 500 处推到 606 处 —— 曲线本身在 δ 很小时曲率更大。

## 修法（三步，都在输出前统一处理，不碰生成端）

1. **删零长段**（`nDup`）：坐标完全相同、且 spray 状态相同才删。box 240 个、
   complex 62、cao 44、tr 42、bin 18。控制器的速度规划在这里会除零，
   KUKA/ABB 直接报 `motion not possible`。
2. **密集区等弧长重采样**（`nRe`，bin 719 点）：只处理"连续点距 < 0.5×pt 且链长
   > 1.2×pt"的密集链，按点距重新等分。采样点还落在抖动曲线上，但密度降下来，
   等效曲率就回到正常量级。真实棱边（正常点距处的大转角）不受影响。
3. **探出点消除 + 发卡弯倒角**（`nSpur` / `nChamf`）：行末点被算到轮廓外一点点、
   下一行又从旁边 0.3mm 处起步，形成"出去再原路回来"的往返（转角 150~175°）。
   这种弯的横向错开量就是两个邻点的间距，圆角救不了，只能**删掉拐点让前后直连**
   —— 转角立刻从 165° 降到 ~40°。带撞件校验（直连段中点离件 ≥ moveClear 才倒角），
   且**迭代到收敛**（删一个会接出新的短段，实测单遍只抓到 1 处，迭代后能抓 4 处）。

## 关键教训

- **别用逐点转角衡量"急转弯"**。点距坍缩时转角会饱和到 180°，但那是 0.03mm 尺度上的
  几何，机器人根本不关心。用 `r = 段长/转角`。
- **别指望圆角**。横向错开 δ 决定掉头半径上限 δ/2，δ 小的时候越平滑越糟。
- **删点比插点有效**。三类问题（零长、密集、探出）都是"点太多、位置由噪声决定"，
  减点即可；插点只会引入新的高曲率。
- **回归要用同口径**。改前 box 的 `<3mm` 显示 0 处，是因为 240 个零长段让
  曲率计算跳过了这些位置 —— 删掉零长段后真实曲率才暴露出来（231 处，
  改前改后一致，属既有问题、非本轮引入）。
