# 第十五轮：回转体（垃圾桶/截锥）改走等高线圈

> 用户原话：**"轨迹不规则，如果点间距小姿态变化大可能会出问题"**
> 样本：`垃圾桶(模拟生成).ply`（`C:/Users/DYF/Desktop/点云/喷涂点云/`，二进制 PLY，43469 点，
> 已用 `E:/tmp_build/userclouds/bin2ascii.py` 转 ascii 后入库为 `cpp/_regress/bin.ply`）
> 参数：行距 12mm / 点距 4mm / 离面 100mm / 速度 200mm/s（界面默认）。

## 这个件的真实几何

不是"一个曲面"，是三块拼起来的：

| 部位 | 范围 | 点数 |
|---|---|---|
| 顶部环形唇边 | z≈184，r 143→175（水平环，宽 32mm） | 6977（16.3%） |
| 圆台侧壁 | z 0→191，r 60→175（锥角 26.6°） | 33216（77.4%） |
| 底面圆盘 | z≈0，r ≤57 | 2726（7.6%） |

三者靠棱边的法向过渡点连成一个 91.2%~100% 的块，`detect_curved_patch` 判成曲面。

## 三个根因（都跟"曲面"本身无关）

### ① 行走向：`cross(n, eIdx)` 逼出来的是"平面截线"，不是等高线

`surf_march` 的切向 = 法向 × **固定的横向轴 eIdx**。这等于"行 = 等 eIdx 的平面截线"。

- 在**柱面**（曲型板）上，截线正好是沿长边的直线 —— 正确，所以以前没暴露。
- 在**回转面**上，过轴平面截锥面得到的是**双曲线** —— 每条行沿母线从上沿直插到底面中心。

实测 27 行全部终止在轴心，母线间距外圈 **20.4mm**、内圈 **7.0mm**（设定 12mm），
外沿还有 r 到 199mm 的外推钩子（点云最大 r 只有 175）。

### ② 平盘混进曲面块

沿 n0 的高度场在水平盘上是**常数**，梯度为 0 → 等值线无定义 → 追踪退化成直线横穿。

### ③ 姿态限幅写死 6°/点

点距 4mm、速度 200mm/s → 50 点/s → **300°/s** 的末端角速度。
多数六轴机器人 TCP 姿态角速度上限 100~200°/s，跟不上就是到位滞后/超调/拐角甩出去。

## 改法

### a) 回转面判定 + `isoH` 模式

`gen_surface_rows` 里三项合取（`ratio` / `cover` / `aspect`）：

| 判据 | 曲型板 | 垃圾桶 | 门限 |
|---|---|---|---|
| 沿长轴高程起伏 = 箱内 h 极差 ÷ 箱内 eRow 跨度 | 0.372 | 0.618 | > 0.10 |
| (u,v) 投影方位覆盖 | 100% | 100% | ≥ 300° |
| 外接框宽高比 | **3.11** | 1.00 | **< 1.8** |

> 前两条曲型板都过，**只有宽高比把它挡回去**。少这一条，曲型板会被判成回转体，
> 行被切成 6 个点的碎片、覆盖率 92%→55%、残差 8.88→18.93mm。

`surf_march(..., isoH=true)`：上坡方向从固定的 `eIdx` 换成**高度场梯度**
`∇h = n0·(n·n0) - n`，切向 `t = cross(n, ∇h)` → 行 = 等高线圈。
梯度≈0 处（平面区）直接判定"行到此为止"，不再直线横穿。

锚点改为**逐层等弧长推进**：`h += L·|∇h|(该层)`，`|∇h|` 取该高度层的中位。
（用全局平均会让坡缓处行距 72mm、坡陡处 7mm —— 实测覆盖率只有 54.7%。）

### b) 块内平盘剥离

**不用 RANSAC**：锥面在 2.4mm 公差下就能凑出 3043 点的伪平面（法向 (0.85,-0.25,0.46)），
把真正 2726 点的底面比下去。

改用**沿 nf 的 1mm 高度直方图**找尖峰 —— 平盘在高度场上必然是尖峰：

| | 峰值箱点数 | 占比 | 2D 最小宽度 | 判定 |
|---|---|---|---|---|
| 曲型板 | 4797 | 4.8% | 213mm | 不剥（占比 < 5%，而且它是弯曲板被切出来的带） |
| 垃圾桶顶环 | 6977 | 16.3% | 453mm | **剥** |
| 垃圾桶底面 | 2726 | 7.6% | 117mm | **剥** |

两条判据：峰值 ±0.2×行距 的点占块 ≥5%，且垂直 nf 的 2D 最小宽度 ≥3×行距。最多 3 轮。

### c) 姿态限幅按角速度反算

```
slewDeg = clamp(150°/s × 点距 ÷ 速度, 0.5°, 6.0°)
```
200mm/s、4mm → **3.00°/点 = 150°/s**。曲型板的 `seg_max` 顺带从 9.038 降到 7.658。

## 结果

| 指标 | 改前 | 改后 |
|---|---|---|
| 面数 | 1（曲面块，含顶环和底面） | **3**（锥面 + 顶环 + 底面） |
| 锥面行数 | 27 行（沿母线放射） | **18 圈等高线** |
| 行距 | 母线间距 20.4mm(外)~7.0mm(内) | **12.00mm 均匀** |
| 覆盖率 | 93.1% | **100%** |
| 贴合残差 | 5.19mm | **1.65mm** |
| 枪位偏离 `gun_jitter` | — | p95 5.2 / max 7.3mm |
| 姿态步进 `normal_step` | — | p95 3.02° / max 3.12°（≈150°/s） |
| 总行数 / 点数 | 27 / 3297 | 57 / 16494（多出的是顶环 29 行 + 底面 10 行） |

曲型板回归（**位置类指标一字未变**）：

| 指标 | 改前 | 改后 |
|---|---|---|
| 行数 / 行距 / 覆盖率 / 贴合残差 | 14+4 行 / 11.76mm / 92.2% / 8.88mm | **完全相同** |
| `gun_jitter` p95 / max | 4.6 / 10.7mm | **3.2 / 7.9mm** |
| `normal_step` p95 | 2.14° | **1.38°** |
| `seg_mean` / `seg_max` | 4.843 / 9.038mm | **4.959 / 7.658mm** |

其余 25 个样本 **25/25 逐字节一致**（`reg_r15.txt` 对 `reg_final15.txt`）。

## 已知但本轮没做

**顶环唇边用平行扫描很浪费**。环宽只有 32mm、外径 350mm，平行布行要扫 29 遍，
有效行程只占环面积的 13%，其余全是空走（图上看到的那一大片横向线就是它）。
对环形/窄面更合理的做法是「内缩轮廓走一圈」。已记入 HANDOFF 第 7 节第 17 条。
