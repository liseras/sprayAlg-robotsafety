# 第十轮 UI 验收：曲型板（curved.ply）曲面网格 + 枪姿连续性

命令（查看器命令行自运行模式，`--shot` 用 RenderTargetBitmap 直接渲染视口，不受窗口遮挡/焦点影响）：

```
SprayTrajViewer.exe --ply cpp\_regress\curved.ply --auto --show-plane 1 --show-traj 1 \
    --show-cloud 0 --view <iso|top|front|side|face> --shot <png> --exit
```

> `--view face` 是第十轮新增的预设：**沿面0自身法向正视**（正交相机）。
> 曲面件在工件坐标系里没有"正对"方向，top/front/side 全是斜视，
> 验收"行是否铺满面"必须用 face，否则会因斜视 + 100mm standoff 偏移误判成"漏覆盖"。

## 截图与结论

| 图 | 看什么 | 结论 |
|---|---|---|
| `曲型板_侧视_曲面网格与行.png` | 网格是不是曲面 | 蓝色面片呈**拱形弧面**（不是 4 顶点平板），红色行**平行贴着弧面**排布 |
| `曲型板_面法向正视_行覆盖.png` | 行是否铺满面 | 14 行横向铺满整个面片，行随曲面**起伏呈波浪**，两端为卷边带 |
| `曲型板_俯视_轨迹.png` / `曲型板_前视_轨迹.png` | 轴向斜视 | 轨迹悬在面上 100mm（standoff），投影上相对面片有偏移，属正常 |
| `曲型板_轴测_网格.png` | 整体 | 曲面块 + 耳朵凸台（第二个平面）各自成面 |
| `曲型板_轴测_点云叠加.png` / `曲型板_俯视_点云叠加.png` | 面片 vs 点云 | 面片贴合点云轮廓；点云为洋红色（第十轮故意保留叠加，用于核对面片没跑偏） |

## 独立覆盖度核对（不吃算法自报）

`E:\tmp_build\dbg\cover_check.py`：用原始点云 + 轨迹 CSV（枪位还原到面：
`面点 = 枪位 + 100·(I,J,K)`，CSV 的 (I,J,K) = −n）重算"每个点到最近行点的距离"，
阈值取与 `spray_traj.cpp` 相同的 `max(0.75×行距, 0.75×L) = 8.82mm`：

```
覆盖率(<=8.82mm) = 90.7%   平均残差RMS = 9.00mm
p50 = 3.55mm  p75 = 5.17mm  p90 = 7.52mm  p95 = 20.53mm
```

与算法自报的 **92.2% / 8.88mm** 一致（差在：这里没做 SOR 去噪、也没剔除耳朵凸台点与洞补点）。

> ⚠️ 俯视图里"红色只在工件右侧"是**投影错觉**：轨迹在面法向 100mm 处，
> 该曲面平均法向 (-0.562,0.224,0.796) 横向分量很大，俯视时整片轨迹相对面片横向平移。
> 换 `--view face` 正视即可确认行是铺满的。
